# Asset Sources

All visuals are generated at runtime by `src/utils/PixelArtGenerator.ts`,
`src/world/PlotRenderer.ts`, and inline `make.graphics` calls in GameScene.
**No external art assets are bundled.** No commercial game assets were copied.

Audio: none bundled yet (hook reserved). When adding audio, list every file
here with creator, source URL, and license. Only CC0 / CC-BY / public domain /
purchased licenses are permitted. If license is unclear — do not ship it.

Placeholder icons in `public/icons/` were generated programmatically for this
project and are original.
